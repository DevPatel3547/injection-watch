InjectionWatch browser extension: privacy policy

Version 0.2.0. Applies to the extension only; the project's feed and API are covered by docs/ethics.md.

What the extension does

It reads the page you are viewing, extracts text that is hidden from humans but readable by AI agents (hidden elements, comments, meta tags, attributes, structured data, invisible Unicode), and scores it with a fixed rule set bundled inside the extension. Results are shown as a badge and in the popup.

Data collected

  • By default: none. All scanning happens locally. Findings for open tabs are kept in memory only and discarded when the tab closes.
  • Settings (reporting on/off, endpoint) are stored with chrome.storage.local on your device.
  • Optional reports. Only if you (1) turn reporting on in Options, (2) click Report on a finding, and (3) confirm a dialog showing the exact data, the extension sends one HTTPS request to the endpoint you configured containing: the page URL as scheme + host + path (query string and fragment removed; URLs with embedded credentials are never sent), a SHA-256 hash of the normalized hidden text, its category, its technique, and the extension version.

Never collected or sent

  • Page content, the hidden text itself, excerpts, form data, or screenshots.
  • Cookies, credentials, browsing history, other tabs, or any identifier for you or your browser (requests use credentials: "omit" and referrerPolicy: "no-referrer").
  • Anything from incognito windows.

Remote code

None. All scripts and detection rules are packaged in the extension; it never downloads or evaluates code.

Permissions

  • storage: remember your settings.
  • Content script on http/https pages: needed to scan the page you are viewing, locally.
  • Optional host permission for the single report endpoint you configure, requested only when you save it.

Caveat

A URL path alone can be sensitive (for example /users/jane-doe/settings). The confirmation dialog lets you decline. Do not report pages that are only reachable while logged in.

Contact

Questions or deletion requests for a report you sent: open an issue in the project repository or use the contact address listed there. Submitted reports contain no identifier, so we can only locate one if you give us the URL and the time you sent it.
